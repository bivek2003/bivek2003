## Featured Projects

### 🔬 [TICTAC — Target Illumination Clinical Trial Analytics](https://github.com/unmtransinfo/TICTAC-API) *(org project)*
**FastAPI · React · Recharts · PostgreSQL · Docker**

Full-stack biomedical research platform aggregating 190,000+ clinical trials to score and rank drug-target associations. Built the complete frontend, backend, and REST API from scratch.
- Interactive scatter plots, evidence tables, and drill-down views
- Direct source links to ClinicalTrials.gov and PubMed for traceability
- Deployed in production at UNM Health Sciences

### 🧪 [SmartFilter — Chemical Data Filtering Platform](https://github.com/unmtransinfo/SmartFilter-UI) *(org project)*
**React · Flask · PostgreSQL · Redis · Docker**

Production web application enabling researchers to apply SMARTS chemical filters to large batch datasets — no coding required.
- Handles large-scale concurrent dataset analysis in production
- Result caching for repeated queries
- Used actively by UNM cheminformatics research team

### 🛡️ [Deepfake Detection Platform](https://github.com/bivek2003/DeepFake_Detection)
**FastAPI · React · PyTorch · Celery · Redis · PostgreSQL · Docker**

Production-architecture media forensics platform for detecting AI-manipulated images and videos.
- Grad-CAM heatmap explainability showing which image regions triggered detection
- Async video processing pipeline with frame-by-frame analysis via Celery workers
- Downloadable PDF forensic reports with metadata and confidence scores
- Full CI/CD pipeline via GitHub Actions; Dockerized multi-service deployment

### 🏛️ [Distributed Auction System](https://github.com/bivek2003/Auction-House-System)
**Java · Sockets · Multithreading**

Distributed system with a central bank, multiple auction servers, and concurrent bidding agents — real-time transactional settlement across concurrent threads.
